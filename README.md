# Netflix Data Analysis & Cleaning Project  

This project explores the Netflix titles dataset using Pandas for data analysis, transformation, and cleaning. It demonstrates practical skills in:

Data exploration (head, tail, info, describe, missing values)

Selection and filtering with [], .loc, and .iloc

Conditional queries and sorting

Updating and transforming columns (feature engineering)

GroupBy aggregation and visualization

Data cleaning (handling missing values, fixing inconsistent formats, converting datatypes)

The workflow progresses through 125 structured questions, covering the full lifecycle of a data project — from raw dataset inspection to a cleaned, ready‑to‑use CSV file (netflix_clean.csv).

This repository showcases:

Hands‑on Pandas practice with real‑world data

Systematic cleaning pipeline for reliable analysis

Reproducible Jupyter Notebook documenting every step
